Monitoramento de temperatura da geladeira

Projeto pessoal em desenvolvimento — ESP32, sensor, API e dashboard

Projeto criado para acompanhar a temperatura do freezer e do refrigerador, registrar as medições e futuramente visualizá-las em um painel. O projeto conecta refrigeração, elétrica, sensores, programação e Internet das Coisas.

Objetivo

Coletar temperaturas periodicamente, enviá-las para uma API e manter um histórico para consulta em gráficos.

Etapa atual

O ESP32 e o sensor DS18B20 já foram montados e testados. A API está em construção. Por isso, o projeto ainda não é apresentado como concluído.

Ferramentas e tecnologias

  • ESP32 e sensor DS18B20
  • Protoboard e resistor de 4,7 kΩ
  • Arduino IDE
  • Laravel, API e banco de dados
  • Git e GitHub

Próximas etapas

  • Criar o recebimento e armazenamento das medições
  • Adicionar testes à API
  • Desenvolver o dashboard
  • Planejar o funcionamento durante quedas de internet e energia
