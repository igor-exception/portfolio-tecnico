Monitoramento de temperatura da geladeira

Projeto pessoal em desenvolvimento — ESP32, sensores, API e dashboard

Projeto criado para acompanhar a temperatura do freezer e do refrigerador, registrar as medições e futuramente visualizá-las em um painel. O projeto conecta refrigeração, elétrica, sensores, programação e Internet das Coisas.

Objetivo

O objetivo deste projeto é desenvolver um sistema capaz de realizar o monitoramento contínuo, 24 horas por dia e 7 dias por semana, das temperaturas do refrigerador e do freezer da minha geladeira.

A proposta é que as medições sejam realizadas automaticamente pelos sensores, enviadas para uma API e armazenadas para formar um histórico de funcionamento. Essas informações serão apresentadas em uma dashboard com gráficos e dados de temperatura, permitindo acompanhar de maneira simples o comportamento da geladeira ao longo do tempo.

Além de visualizar a temperatura atual, o histórico permitirá observar variações e entender como as temperaturas do refrigerador e do freezer se comportam durante diferentes períodos, sem depender de medições manuais.

A primeira etapa do projeto já foi concluída: desenvolver e validar um protótipo capaz de realizar a leitura de temperatura utilizando um ESP32 e o sensor DS18B20. Com essa etapa funcionando, o projeto pode avançar para o envio, armazenamento e visualização dos dados.

Etapa atual

O primeiro protótipo com ESP32 e sensor DS18B20 foi montado e testado com sucesso. O sistema já consegue captar as variações de temperatura e apresentar as leituras em tempo real pelo Monitor Serial do Arduino IDE.

Com a etapa de aquisição de temperatura validada, o desenvolvimento agora avança para a comunicação com a API, armazenamento das medições e, posteriormente, construção da dashboard.
